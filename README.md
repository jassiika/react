# Task Management REST API

A simple **Task Management REST API** built with **Node.js and Express.js**.
This project demonstrates the fundamentals of REST APIs, HTTP methods, middleware, request handling, CRUD operations, and unique ID generation.

Features

* Create a new task
* Get all tasks
* Get a task by ID
* Update an existing task
* Delete a task
* Input validation for required fields
* Unique task IDs using UUID
* JSON request and response handling
* RESTful API structure
